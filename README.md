Температура: считывается через WMI; на некоторых ноутбуках (включая HP с Ryzen) требует прав администратора или недоступна из‑за ограничений ACPI. Отображается как «н/д», если доступ невозможен.
Частота: берётся текущая (current), если недоступна — максимальная (max). На Ryzen 3500U частота динамически меняется в зависимости от нагрузки и питания.
Загрузка: среднее значение по всем ядрам за 1 секунду (interval=1.0, percpu=False) — это даёт более плавный график по сравнению с короткими интервалами.
